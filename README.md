# Komentář k zákonu č. 198/2009 Sb., o rovném zacházení a o právních prostředcích ochrany před diskriminací a o změně některých zákonů (antidiskriminační zákon)

Otevřený komentář k antidiskriminačnímu zákonu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; působnost, přímá a nepřímá diskriminace, obtěžování a pronásledování, přiměřená opatření pro osoby se zdravotním postižením, přípustné rozdílné zacházení a právní prostředky ochrany před diskriminací.

Konsolidované znění: dokument e-Sbírky `SB-2009-00198_2018-01-01`.
